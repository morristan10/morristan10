## 譚亮佑 Tan Liang Yu

國立成功大學機械工程學系，雙主修政治學系。我關心人怎麼使用工具，以及工具怎麼回應人的需要。目前的興趣橫跨工程與社會科學：從硬體、機電系統，到研究者每天實際用到的軟體工具。

I study Mechanical Engineering with a double major in Political Science at National Cheng Kung University (NCKU), Taiwan. I'm interested in how people use tools and how tools can be shaped around people, from mechatronic systems to the software researchers rely on every day.

### 代表作 · Selected work

**[Qualia Coder](https://github.com/Matrttie/qualia-coder)** · [線上使用 Live site](https://matrttie.github.io/qualia-coder/)
給小型研究團隊用的免費、開源質性編碼工具：成員打開一個連結就能一起為訪談逐字稿編碼，不需註冊或安裝，並可比較編碼者間的一致性。以 GitHub Pages 與 Google Apps Script 建置，資料存放在專案擁有者自己的 Google Drive。我和研究夥伴 [@Matrttie](https://github.com/Matrttie) 共同開發。

A free, open-source qualitative coding tool for small research teams: open one link and code interview transcripts together, with no account or install, then compare inter-coder agreement. Built on GitHub Pages and Google Apps Script; the data stays in the project owner's Google Drive. Co-developed with my research partner [@Matrttie](https://github.com/Matrttie).
